# Вариант 09. Система бронирования мест

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Race Condition, lock, SemaphoreSlim, Channel, PLINQ

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать модель зала и свободных мест.
2. Реализовать бронирование и отмену.
3. Смоделировать конкурентную попытку забронировать одно место.
4. Защитить проверку и изменение статуса места одной критической секцией.
5. Ограничить число одновременных запросов.
6. Реализовать параллельную проверку занятости мест.
7. Добавить журнал бронирований.

## Дополнительные задания
8. Добавить очередь ожидания через Channel.
9. Сформировать статистику через LINQ/PLINQ.
10. Сохранять параметры зала в HKCU.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
